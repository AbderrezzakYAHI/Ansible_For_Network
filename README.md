# Ansible for Network

This repository contains practical **Ansible network automation projects** for managing and configuring network devices from different vendors.

## Projects

The repository includes learning projects for:

- **Cisco**
- **Fortinet**
- **Huawei**
- **Juniper**
- **Nokia**

Each project is organized around Ansible and network automation concepts, with vendor-specific configurations and Jinja2 templates.

## Purpose

The goal is to demonstrate how Ansible can be used to:

- Automate network device configuration
- Generate configurations with **Jinja2**
- Reduce repetitive manual tasks
- Apply the same automation approach across different network vendors
